## Changes in this publication

- Dual Screen 0.3.12 and Capture Assistant 0.1.1 add bottom-screen capture assistance while the battle stays visible above; the battery percentage alignment fix is included.
- LegalMon 0.17.1 adds numeric controller entry for Trainer ID and Secret ID.
- Pokémon Services 0.1.3 provides free move relearning without consuming mushrooms.
- Scrollable Start Menu 0.2.1 changes reordering to A to pick up, Up/Down to move, and A to place, with cancellation and persistence checks.
- The all-mods bundle now uses uncompressed classic ZIP entries and a direct GitHub download link. Its files are verified after extraction; the earlier reported damaged-download error was not reproduced locally.

- Auto Breeder 1.0.3 adds keeping improved working parents with duplicate and storage-capacity guards.
- Dual Screen 0.3.9 includes a built-in native-sprite ball picker and battle type-effectiveness badges. Start Menu 0.2.0 adds saved ordering and folders.
- The six generation/export compatibility packages include the completed [native legality corrections](LEGALITY-FIXES.md). Ball Shortcut is updated to 0.2.2.

- LegalMon 0.17.0 adds egg inheritance and bounded parent chains, supported Sketch sources, earlier-stage machine/tutor moves and evolution-level teaching proofs. Its coverage report retains the remaining limits.
- FRLG Dual Screen 0.3.12 is based on Kanto Gear 3.3.3. It adds companion integrations for this collection, including Home shortcuts, native-menu fallback, editors, encounter tools and Live QoL settings. Quick Heal Party and Capture Assistant now have dedicated Home tiles instead of Live QoL toggles.
- Day Care Viewer 0.2.1 adds native deposits, paid withdrawals and daycare teleports; egg collection remains on Four Island.
- Pokémon Services 0.1.1 adds the Pokémon Centre tools: remote native PCs, healing, shops, move services, daycare management and menu shortcuts.
- Quick Heal Party 0.1.0 and Capture Assistant 0.1.1, Quiet EXP 0.1.0, Scrollable Start Menu 0.2.0 and the completed QoL compatibility releases are included. Battle Type Hints and Move Inspector have been removed from current packages. See [the QoL fix report](../qol/FIXES.md).

Downloads contain 38 current individual ZIPs: ten main packages and 28 in `downloads/QOL/`. Each individual ZIP has its own root manifest and declared entry point. The additional [manual-install bundle](https://github.com/CapnJames95/gen1recomp-mod-releases/releases/download/v1.0.0/gen1recomp-all-mods-manual-install.zip) contains all 38 extracted mod folders and `INSTALL.txt`; it is not a launcher-import package. Superseded downloads, checksum sidecars and macOS metadata are excluded. Internal integrity hashes remain in `releases.json`.

This is a snapshot of completed custom-mod releases, not an automatic sync or an update check for unrelated community mods. Dual Screen has been tested only on AYN Thor; other dual-screen devices are untested. A full combined gameplay run remains outside the automated verification.

Four-Item Wheel is temporarily withdrawn. Its development files are preserved locally for future work.
