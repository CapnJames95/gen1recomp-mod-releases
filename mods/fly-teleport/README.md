# Teleport 0.3.0

Supports all five Gen 3 games, independently or through QoL Suite. Open START → QOL → TELEPORT when using the Suite.

The main screen offers **Fly Destinations**, **Points of Interest** and **Saved Locations**, in that order. Each opens its own list; Back returns to the main screen. Left/Right skips five rows. Fly destinations retain native progression flags. POIs include services, activity entrances, training locations and dungeon entrances; these recognise native save progress and recorded map visits. Locations without native visit records use area-progress milestones. **Unlock All**, at the bottom, defaults OFF and bypasses destination progression locks only. It does not override activity or arrival safety checks.

**Saved Locations → Save current position** opens the native naming keyboard. Up to 50 named positions are stored per save/edition, including facing direction. Each can be renamed, moved up/down, replaced with your current position or deleted after confirmation. Use Favourites, the last ten Recent destinations, or Return to previous location. Save the game normally to keep these changes.

Teleport validates live map data and avoids walls, ledges, warp tiles, objects and coordinate-script triggers. Surf/Dive points require the relevant owned HM and badge. Linked play, active Safari games, battles, cutscenes, restricted facilities and temporary maps are blocked. Native map-entry scripts and ordinary interaction requirements still apply. Berry patch destinations appear with Hoenn Tools enabled; encounter destinations open Encounter Tour when installed.

This local update has automated native-data coverage; manual device gameplay validation is still required.

Safari entrance POIs land outside reception in all five games. Enter and pay normally; old saved/recent destinations inside Safari reception are blocked.

Building POIs land just outside the native entrance door, including services on upper floors. Enter normally to reach the service; cave and other exploration POIs retain their existing destinations.
