# QoL package

[Download FRLG QoL Suite 0.3.9](https://github.com/CapnJames95/gen1recomp-mod-releases/releases/download/v1.3/frlg-qol-suite-0.3.9.zip) — 32 components (31 applicable per game) in one import.

Standalone QoL packages are no longer distributed. Import the suite, disable any older standalone copies, and restart. Use **START → QOL → QOL SETTINGS** for individual toggles/options and **QOL SHORTCUTS** for key bindings and their valid contexts. Dual Screen 0.3.21+ recognises the bundled features.
