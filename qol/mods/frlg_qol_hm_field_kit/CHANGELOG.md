# Changelog

## 0.2.4
- Sweet Scent can use any non-egg party member without teaching the move on engine 0.3.42+. Field Kit and the existing Dual Screen tile share encounter-terrain checks; native generation and moves/PP are preserved. Older engines are gated.

## 0.2.3
- HM species compatibility is no longer required. Any non-egg party member can supply the native animation after HM ownership is confirmed. Missing HMs remain blocked even when a party Pokémon already knows the move. Native badges and field restrictions remain; non-HM moves still need to be learned.

## [0.1.0]
- Initial FRLG implementation: Use owned HMs with compatible party Pokemon without teaching the move.
