# Safari Zone Tools 0.1.0

Included in QoL Suite 0.3.12. Supports Ruby, Sapphire, Emerald, FireRed and LeafGreen.

Open START → QOL → SAFARI TOOLS, or the Dual Screen Safari Tools tile. Choose Normal, x2, x5 or Unlimited steps and Normal, 50, 99 or Unlimited Safari Balls. Default allowances are unchanged. Settings apply at entry; Refill updates the current game. Unlimited stops depletion while preserving native feeder aging, catch rates and fleeing.

At exhaustion, a Refill/Retire choice appears before normal time-up text. A last-ball throw resolves first; it is never rerolled by the prompt. Refill resets both resources to the configured allowances. Retire follows the native edition-specific exit. Shiny Hunter pauses for the choice. The normal Quick exit uses the native retire confirmation.

Live counters appear in Safari Tools and Dual Screen's Wild Pokémon screen. Wild Pokémon checklist requires Gen3DualScreen. Settings persist through normal save/options storage. Disable this component in QOL SETTINGS to restore normal depletion behavior.
