# Zoom Controls

Open START → QOL → QOL SETTINGS, highlight Zoom Controls and press SELECT for options. Enable or disable the component and choose a keyboard key or controller button. F10 defaults to cycling the engine’s available zoom levels; the controller binding defaults OFF to avoid taking an existing shortcut.

Choose **Toggle Two** to switch between **Toggle Level 1 / 2**. Levels use the engine’s **FIT / OUT / IN** offsets, not fixed percentages; the actual range depends on window size and engine limits. Unavailable choices clamp to the supported range.

Turn **Indoor / Outdoor Zoom** ON to set independent levels. Buildings and caves use Indoor; native outdoor map types use Outdoor. Unknown map types retain the current zoom. Manual changes last until crossing area types or changing the settings. Menus, battles and transitions block the hotkey. Settings persist through the Suite; these controls never change saves or the engine’s base zoom preference.
